# Web-Sovellukset Harjoitus

Yksinkertainen harjoitustyö kurssille **Web-sovellusten perusteet** (OAMK).

## Kuvaus

Sivustolla on kolme sivua:

- **Etusivu** (`index.html`) – esittely ja kuvia
- **Speden Spelit** (`spedenspelit.html`) – Tallentaa 10 parasta tulosta selaimen localStorageen.
- **About** (`about.html`) – tietoa sivustosta ja tekijästä

## Tekniikat

- HTML
- CSS
- JS

## Ominaisuudet

- Responsiivinen ulkoasu
- Toimiva spedenspelit pisteytyksellä
- Parhaat tulokset säilyvät selaimessa
- Navigointi sivujen välillä
